## Featured project

### AI School Attendance Alert (હાજરી એલર્ટ)
A Gujarati-first school attendance system with a dashboard, charts and automatic parent alerts.

| | |
|---|---|
| **What it does** | Records daily attendance, shows class-wise and monthly trends, and alerts parents about absences |
| **Frontend** | React, Vite |
| **Backend** | Python, FastAPI (REST API with auto-generated docs) |
| **Highlights** | Analytics dashboard with graphs, absent-student list with alert status, light and dark theme |
| **Live demo** | [hajri-alert.vercel.app](https://hajri-alert.vercel.app/school) |
